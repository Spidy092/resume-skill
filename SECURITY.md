# Security Policy

## Reporting a vulnerability

Do not disclose a vulnerability or real candidate data in a public issue. Use GitHub's private vulnerability reporting feature for this repository. Include reproduction steps, affected files or versions, and the expected impact without attaching personal resume data.

## Data handling

This skill processes resumes and career evidence locally. Contributors must not add telemetry, upload candidate data, submit applications, or contact third parties without an explicit, documented design change and clear user authorization.

Users should inspect third-party skill code before installation and avoid committing private career evidence to a public repository.
